## 🧾 درباره فروش‌یار

فروش‌یار برای مغازه‌دارها، فروشنده‌های امنیتی و لوازم، و همه کسب‌وکارهای کوچکی ساخته شده که به یک فاکتور **تمیز، فارسی و سریع** نیاز دارند — بدون دردسر نرم‌افزارهای سنگین حسابداری.

همه‌چیز روی گوشی خودتان ذخیره می‌شود: مشتری‌ها، محصولات، فاکتورها و تنظیمات. فقط کافی است در اجرای اول نام و کسب‌وکارتان را وارد کنید و بلافاصله شروع به صدور فاکتور کنید. خروجی هر فاکتور را می‌توانید به‌صورت **PNG، JPG یا PDF** ذخیره کنید یا **مستقیم برای مشتری** بفرستید.

## ✨ ویژگی‌ها

### صدور فاکتور
- 🧾 صدور فاکتور با انتخاب محصول، تعداد آزاد (بدون سقف)، قیمت و **تخفیف و مالیات**
- 🔢 جمع کل به **عدد و حروف فارسی** — همه اعداد برنامه فارسی‌اند
- 👤 انتخاب مشتری از لیست یا ثبت جدید، همراه با اعتبارسنجی شماره تماس ۱۱ رقمی
- 📝 **ذخیره خودکار پیش‌نویس** — اگر از صفحه بروید یا برنامه بسته شود، فاکتور نیمه‌کاره از دست نمی‌رود
- 🖼️ آپلود لوگو، مهر و امضا — چیدمان حرفه‌ای مهر در برگه افقی
- 📄 **متن دلخواه پای فاکتور** (مثلاً شرایط گارانتی یا جمله تشکر) — از تنظیمات قابل تغییر است
- 🏦 درج اطلاعات بانکی و **کد ملی** (برای ثبت چک صیادی)

### خروجی و اشتراک‌گذاری
- 📤 خروجی **PNG / JPG / PDF** با کیفیت بالا و اندازه واقعی A4
- ↔️ انتخاب جهت برگه خروجی **عمودی یا افقی** از تنظیمات — پیش‌نمایش دقیقاً همان خروجی است
- 💬 ارسال **مستقیم برای مشتری** — واتساپ، تلگرام یا هر پیام‌رسان و برنامه دیگری که خواستید
- 💾 دانلود واقعی فایل در اندروید (پوشه `Documents/ForoshYar`)

### تجربه کاربری
- 🎨 **۶ تم رنگی** (طلایی، سبز، نارنجی، صورتی، بنفش، فیروزه‌ای) — هرکدام با حالت **روشن و تاریک**
- 🌐 **۱۰۰٪ آفلاین** — بدون حساب کاربری، بدون دیتابیس ابری
- 🇮🇷 رابط کاملاً فارسی و راست‌به‌چپ با فونت **وزیرمتن**
- 📱 پشتیبانی همزمان از نسخه **اندروید (APK)** و **PWA** (نصب از مرورگر)
- 🔙 مدیریت هوشمند دکمه Back در اندروید

## 📱 نصب روی اندروید

1. به صفحه [**Releases**](../../releases) بروید و آخرین نسخه `Froshyar-x.x.x.apk` را دانلود کنید.
2. روی فایل بزنید؛ اگر اندروید پرسید، اجازه «نصب از منابع ناشناس» را بدهید.
3. تمام! برنامه بدون هیچ ثبت‌نامی اجرا می‌شود.

## 🌐 اجرای نسخه وب

```bash
npm install
npm run dev        # اجرا روی http://localhost:3000
```

نسخه وب یک PWA کامل است و می‌توانید آن را از مرورگر روی صفحه اصلی گوشی نصب کنید.

## 🔨 ساخت APK

### روش خودکار (پیشنهادی) — GitHub Actions

با هر push به شاخه `main`، اکشن [ساخت APK فروش‌یار](.github/workflows/build-apk.yml) به‌صورت خودکار خروجی **امضاشده** را می‌سازد و در Releases منتشر می‌کند. جزئیات بیشتر: [BUILD-APK.md](./BUILD-APK.md)

کلید امضا در خود مخزن قرار ندارد و فقط از طریق سکرت‌های محیط ساخت رسمی استفاده می‌شود.

### روش دستی

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleRelease
# خروجی: android/app/build/outputs/apk/release/
```

## 🧰 فناوری‌ها

| لایه | فناوری |
|---|---|
| فریم‌ورک | [Next.js 16](https://nextjs.org) (خروجی استاتیک) · TypeScript 5 |
| رابط کاربری | Tailwind CSS 4 · shadcn/ui · فونت وزیرمتن · Lucide Icons |
| وضعیت و داده | Zustand + persist (ذخیره ۱۰۰٪ محلی) |
| خروجی فایل | html2canvas-pro · jsPDF |
| اندروید | Capacitor 8 · Gradle 8 · JDK 21 |

## 📁 ساختار پروژه

```
├── src/
│   ├── app/                    # صفحه اصلی اپ (App Router)
│   ├── components/froshyar/    # اجزای برنامه (فاکتور، مشتریان، تنظیمات و...)
│   ├── components/ui/          # اجزای پایه shadcn/ui
│   ├── lib/                    # منطق: فروشگاه state، قالب‌بندی فارسی، خروجی فایل
│   └── hooks/                  # هوک‌ها (دکمه Back اندروید و...)
├── android/                    # پروژه Capacitor اندروید
├── public/                     # فونت، آیکون‌ها، مانیفست PWA و Service Worker
├── assets/                     # آیکون و اسپلش منبع
└── .github/workflows/          # ساخت خودکار APK/AAB
```
